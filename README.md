# 프리콘 서비스 포털 사용법

프리콘(Pre-construction) 서비스 소개, 리스크 자가점검, VE 효과 계산, FAQ, 자료 다운로드를 한 페이지에서 제공하는 정적 웹 포털입니다. 설치나 서버 없이 `index.html`을 브라우저로 열면 됩니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 포털 본문 (현재 사용 버전) |
| `files/precon-service.pdf` | 서비스 소개서 (자료실 다운로드 대상) |
| `files/precon-tech.pdf` | 공법 브로슈어 (자료실 다운로드 대상) |
| `이전버전/index-teal.html` | 네이비톤으로 바꾸기 전(틸·라임 색) `index.html` 사본 |

`index.html`과 `files/` 폴더는 항상 같은 위치에 두어야 다운로드 링크가 동작합니다. 다른 곳에 올릴 때는 두 개를 함께 옮깁니다.

## 열기

1. `index.html`을 더블클릭하거나 브라우저로 끌어다 놓습니다.
2. 상단 메뉴로 각 섹션으로 이동합니다. 지금 보고 있는 영역의 메뉴 항목은 자동으로 강조됩니다.
3. 상단 오른쪽 해·달 버튼으로 라이트/다크 모드를 바꿉니다. 처음에는 기기의 화면 설정을 따르고, 한 번 직접 바꾸면 그 선택이 브라우저에 저장됩니다.
4. 아래로 내려가면 오른쪽 아래에 둥근 `맨 위로` 버튼이 나타납니다.
5. 모바일·좁은 화면에서는 메뉴가 우측 상단 햄버거 버튼(☰)으로 접힙니다. 누르면 메뉴가 펼쳐지고(버튼은 ✕로 바뀝니다), 항목을 누르면 해당 영역으로 이동하면서 메뉴가 자동으로 닫힙니다. 메뉴 바깥을 누르거나 Esc 키를 눌러도 닫힙니다.

## 메뉴별 사용법

| 메뉴 | 사용법 |
|---|---|
| 홈 | 포털 소개와 핵심 수치를 확인합니다. |
| 서비스 | 설계 검토, VE, 시공성 검토, 리스크 도출, 원가 검토 5개 서비스를 확인합니다. |
| 참여 단계 | 기획 → 설계 → 프리콘 → 시공 단계별 프리콘팀의 역할을 확인합니다. |
| 공법·기술 | BIM 간섭 검토, Top-Down, PC 공법의 내용과 기대 효과를 확인합니다. |
| 리스크 점검 | 지반·인접 시설·공기·민원·설계 변경·기술·수급 6개 영역 12개 항목 중 해당하는 항목을 체크합니다. 오른쪽에 사전 검토 필요도(낮음 / 보통 / 높음), 점수, 우선 검토 권장 영역이 바로 표시됩니다. `선택 초기화`로 모두 해제합니다. |
| VE 계산기 | 금액 단위(원·천원·백만원·억원)를 고르고 기존안 금액과 대안 금액을 입력하면 절감액, 절감률, 비교 막대가 표시됩니다. 대안이 더 크면 증액(−)으로 표시됩니다. `입력 초기화`로 비웁니다. |
| FAQ | 검색창에 키워드(예: VE, 공기, 비용)를 입력하면 해당 질문만 남습니다. 검색창 아래 카테고리 버튼(전체·서비스 일반·VE·원가·리스크·공법·기술·BIM·이용·문의)을 누르면 그 분류만 보이고, 검색어와 함께 쓰면 두 조건에 모두 맞는 질문만 남습니다. `전체`를 누르면 카테고리 선택이 풀립니다. 질문을 눌러 답변과 근거를 펼칩니다. |
| 자료실 | 자료 목록에서 이름·설명·파일명·용량을 확인하고 `다운로드` 버튼을 누르면 PDF가 새 창 없이 바로 저장됩니다. 저장되는 파일명은 한글입니다(프리콘_서비스소개서.pdf, 공법기술_브로슈어.pdf). |

## 결과 해석

- 리스크 점검 점수는 항목별 가중치(1~3점)의 합이며 최대 24점입니다. 점수 비율이 25% 미만이면 낮음, 50% 미만이면 보통, 그 이상이면 높음으로 표시합니다.
- VE 절감률은 (기존안 − 대안) ÷ 기존안 × 100입니다.
- 두 기능 모두 참고용 자동 계산입니다. 실제 리스크 평가와 원가 판단은 현장 조사와 전문가 검토를 거칩니다.

## 내용 수정 방법

- **자료 교체**: `files/` 안의 PDF를 같은 파일명으로 덮어쓰면 링크는 그대로 동작합니다. 다만 자료실 목록의 용량(KB) 표기는 직접 적은 값이라 파일이 바뀌면 `index.html`의 `file-size` 부분을 함께 고칩니다.
- **자료 추가**: `index.html`의 `<ul class="file-list">` 안에서 `<li class="file">` 블록 하나를 복사해 제목·설명·파일명·용량을 바꾸고, 링크는 `href="files/파일명"`, 저장 이름은 `download="한글이름.pdf"`로 맞춥니다.
- **문의처**: `index.html` 하단 푸터의 `문의: 프리콘팀 (연락처를 입력하세요)` 문구에 담당 연락처를 입력해야 합니다. 아직 입력되지 않았습니다.
- **디자인**: 색·글꼴·여백은 `index.html` 상단 `<style>`의 `:root` 변수(`--navy-*`, `--gold`, `--space-*` 등)에서 한 번에 바꿉니다. 다크 모드 색은 바로 아래 `[data-theme="dark"]` 블록에서 바꿉니다. 현재 색 구성은 네이비·골드 톤입니다.
- 편집은 텍스트 편집기(메모장, VS Code 등)로 하고, 수정 전에는 `이전버전/`에 사본을 남겨 두는 것을 권장합니다.
